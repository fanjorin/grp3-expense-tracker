# Expense Tracker UI/UX Case Study

## Problem

Users needed a simple way to:

- Track expenses
- Categorize spending
- View financial summaries

## Research

Studied:

- Budgeting apps
- Finance dashboards
- Mobile-first interfaces



## Design Decisions

### Dashboard

Prioritized:

- Balance visibility
- Expense summaries
- Quick actions

### Typography

Selected fonts to improve readability.

## Challenges

### Font Consistency

Issue:

Fonts rendered differently during frontend implementation.

Impact:

Visual mismatch between Figma and deployed application.

Solution:

Created font specification documentation and standardized font usage.

## Lessons Learned

- Better design handoff reduces implementation issues.
- Design systems should be established earlier.
- Developer-designer communication is critical.
